# Security policy

## Supported versions

| Version | Supported |
| ------- | --------- |
| 1.1.x   | Yes       |
| < 1.1   | No        |

## Reporting a vulnerability

Please do not open a public issue. Use **Report a vulnerability** on the repository's
**Security** tab, which opens a private advisory that only the maintainers can see, or email
security@example.com.

You will get a reply within three working days, and a fix or a plan within 30 days. We credit
reporters in the published advisory unless you ask us not to.
