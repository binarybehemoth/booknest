# Contributing to BookNest

Thanks for helping! Bug reports, documentation fixes and small features are all welcome.

## Before you start
- Search the issues first; comment on one before starting anything larger than a small fix.
- Issues labeled `good first issue` are a good place to begin.

## Making a change
1. Fork the repository and create a branch from `main`, named after the change.
2. Start PostgreSQL with `docker compose up -d`, then run `npm install` and `npm test`.
3. Keep each pull request to one change, with tests for new behavior.
4. Open the pull request against `main` and fill in the template; link the issue (`Closes #12`).

A maintainer reviews within a week. Every conversation must be resolved before merging.

By taking part you agree to follow our [Code of Conduct](CODE_OF_CONDUCT.md).
